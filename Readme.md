# API Endpoints

---

## Houses

#### Get all houses

- **Method:** `GET`
- **Route:** `/houses`

#### Get a single house

- **Method:** `GET`
- **Route:** `/houses/:id`

---

## Students

#### Get all students

- **Method:** `GET`
- **Route:** `/students`

#### Get a single student

- **Method:** `GET`
- **Route:** `/students/:id`

#### Create a student

- **Method:** `POST`
- **Route:** `/students`

#### Update a student

- **Method:** `PUT`
- **Route:** `/students/:id`

#### Delete a student

- **Method:** `DELETE`
- **Route:** `/students/:id`
